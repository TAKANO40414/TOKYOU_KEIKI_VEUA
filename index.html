Features

現場に必要な機能を、すぐに。

⚡
インストール不要
Python も Node.js も必要ありません。ダウンロードしてダブルクリックするだけで即起動。既存の検品環境を一切変えずに導入できます。
🌐
ネットワーク対応
SMB/AFP ネットワーク共有ドライブのファイルも直接読み込み。UNCパス対応。タイムアウト対策済みの非同期I/Oで安定動作します。
📊
9つの表示タブ
概要・ログ・チャプター・イベント・欠陥・結果・機械・環境・画像を一画面に集約。欠陥カードには位置バーと欠点画像を表示。
🔍
欠陥画像ビューア
欠点(D)・参照(R)・形状(S)の3種画像を並列表示。D+S の合成画像を自動生成。ホイール拡縮・ドラッグ移動・全画面表示に対応。
💾
スマートキャッシュ
一度読んだファイルのログ情報はキャッシュに保存。次回以降の一覧表示が大幅に高速化。バージョン管理で古いキャッシュを自動廃棄します。
🖥
他端末から閲覧可能
起動したPCのIPアドレスをブラウザで開けば、同じネットワーク内のタブレットやスマートフォンからも同じ画面を確認できます。

How to use

4ステップで即使える

01
ZIPを展開
ダウンロードしたZIPをデスクトップなど任意の場所に展開します。
02
起動スクリプト実行
Windows は install.bat → その後 PC5Viewer起動.bat。Mac は .command をダブルクリック。
03
フォルダを選択
「📂 参照...」からネットワークドライブ上の検品データフォルダを指定します。複数フォルダの同時表示にも対応。
04
ファイルをクリック
一覧からPC5ファイルをクリックすると、概要から欠陥画像まですべてのデータが表示されます。

まずはデモで体験する

ダウンロード不要。ブラウザだけでインターフェースを確認できます。
