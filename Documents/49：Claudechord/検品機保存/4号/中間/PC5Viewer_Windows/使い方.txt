■ PC5 ビューア - インストール手順 / 使い方（Windows版）
================================================
Version 2.1   対応OS: Windows 10 / Windows 11 (64ビット)
================================================


【配布フォルダの構成】
  PC5Viewer_Windows\
    ├ インストール.bat      ← まずこれを実行（管理者として）
    ├ pc5_web_viewer.py    ← メインプログラム（Python）
    ├ viewer.html          ← 画面ファイル
    ├ PC5Viewer起動.bat    ← 起動ファイル
    ├ アンインストール.bat
    └ 使い方.txt


════════════════════════════════════════════════
【インストール手順】
════════════════════════════════════════════════

■ STEP 1: Python をインストール（初回のみ）
  ─────────────────────────────────────────
  1. https://www.python.org/downloads/ を開く
  2. 「Download Python 3.x.x」をクリック
  3. ダウンロードしたファイルを実行
  4. ★重要★ 「Add Python to PATH」に必ずチェックを入れる
  5. 「Install Now」をクリック
  6. インストール完了後、PCを再起動（推奨）

  ※ すでに Python がインストール済みの場合はスキップ

■ STEP 2: PC5ビューアをインストール
  ─────────────────────────────────────────
  1. 「インストール.bat」を右クリック
  2. 「管理者として実行」をクリック
  3. 自動で以下が行われます：
     ・C:\Program Files\PC5Viewer\ にファイルをコピー
     ・Flask（必要なライブラリ）を自動インストール
     ・デスクトップに「PC5ビューア」ショートカット作成
     ・スタートメニューに登録
     ・ファイアウォール例外追加（他PCからのアクセス用）

■ STEP 3: 起動確認
  ─────────────────────────────────────────
  デスクトップの「PC5ビューア」をダブルクリック
  → 黒いコンソール画面が開き、ブラウザが自動で起動します


════════════════════════════════════════════════
【PC5ファイルの開き方】
════════════════════════════════════════════════

  1. ブラウザ上部の「📂 参照...」ボタンをクリック

  2. フォルダ選択モーダルが開く
     ・「ドライブ一覧」からネットワークドライブを選択
     ・または入力欄にパスを直接入力

  3. ★複数フォルダを同時に開く場合★
     フォルダの左のチェックボックスで複数選択
     例: 4_GO ☑ と 2_GO ☑ を両方チェック

  4. 「✔ 選択して開く」をクリック

  5. 表示期間を選択（直近7日 / 30日 / 3ヶ月 / 全期間）
     ※ 初回は「直近7日」が高速です
     ※ 2回目以降はキャッシュにより即座に表示

  ★ ファイル一覧は「欠点あり」のみ表示されます


════════════════════════════════════════════════
【各タブの説明】
════════════════════════════════════════════════

  欠陥      欠点ごとの画像と詳細情報
            ・欠点位置をメートルで表示（📍 5.63 m）
            ・ロール全体での位置分布バー
            ・画像クリックで拡大
  概要      製品名・注文番号・検品時刻などの要約
  ログ      LogTable の全データ
  チャプター ChapterTable（ロール長さなど）
  イベント  EventTable
  結果      ResultTable
  機械      MachineTable
  環境      EnvironmentTable
  画像      ファイル内の全画像


════════════════════════════════════════════════
【他のPCやタブレットから開く】
════════════════════════════════════════════════

  PC5ビューアを起動すると、黒い画面に
  ネットワークアドレスが表示されます：

    http://192.168.1.10:8765

  → 同じネットワーク内の他PCのブラウザで
    このアドレスを開くだけで閲覧できます


════════════════════════════════════════════════
【終了方法】
════════════════════════════════════════════════

  黒いコンソール画面の「×」ボタンで閉じる


════════════════════════════════════════════════
【アンインストール】
════════════════════════════════════════════════

  「コントロールパネル」→「プログラムのアンインストール」
  →「PC5 ビューア」→「アンインストール」

  または「アンインストール.bat」を管理者として実行


════════════════════════════════════════════════
【トラブルシューティング】
════════════════════════════════════════════════

  ▼ ブラウザが開かない
    → http://localhost:8765 を手動で開く

  ▼ 「Python が見つかりません」エラー
    → STEP 1 の手順で Python をインストール
    → 「Add Python to PATH」にチェックを入れたか確認

  ▼ ネットワークのファイルが遅い / 表示されない
    → 表示期間を「直近7日」にする
    → 2回目以降はキャッシュにより高速になります

  ▼ ポート8765 が使用中
    → タスクマネージャーで「python.exe」を終了して再起動
